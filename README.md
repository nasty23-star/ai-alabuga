# Арена переговоров

Telegram Mini App: текстовый тренажёр переговоров. Пока бэкенд не подключён, работает встроенный мок по контракту API.

## Запуск

```bash
pnpm i
pnpm dev
```

Откройте адрес из вывода Vite (обычно `http://localhost:5173`). Если порт занят, Vite возьмёт следующий. В Telegram Mini App укажите этот адрес как URL веб-приложения.

```bash
pnpm lint
pnpm build
```

## Подключение бэкенда

В `.env`:

```
VITE_API_MODE=http
VITE_API_BASE_URL=https://api.example.com
```

Клиент шлёт `Authorization: Bearer`, `Idempotency-Key` на создающих `POST` и читает ход как `text/event-stream`. Экраны ходят в один интерфейс `Api` — мок и HTTP взаимозаменяемы.

## Мок

В реплике: `/deal` — условия сошлись, `/leave` — собеседник ушёл, `/fail` — поток оборвался, ход не записан. Без команды схождение на каждом четвёртом ходе. Импорт собеседника с `person_id: "unavailable"` отвечает 503.

Геймификация (бейджи) включается тумблером в настройках только для логинов `Okotw` и `ProjectMafia`.
